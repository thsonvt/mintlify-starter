## Full Article

17th October 2026 - Link Blog Inline rendering with document​.currentScript. Lean Rada describes a neat trick that takes advantage of the document.currentScript property. You can use that to drop in a tiny inline &lt;script> element that replaces itself when the page loads: The year is &lt;script> document.currentScript.replaceWith( new Date().getFullYear())&lt;/script> If you define a shortcut function like this: $=(...n)=>document.currentScript.replaceWith(...n) You get a tiny template language: The year is &lt;script>$(new Date().getFullYear())&lt;/script>
