## Summary

Zach Kehs highlights the limitless potential for software to degrade over time, contrasting it with the physical constraints of building structures.

## Key Insights

> "If you continue to add floors and rooms to a building forever, it will collapse."
>
> — Zach Kehs discussing the limitations of physical structures compared to software.

> "The code can always get worse."
>
> — Kehs emphasizing the ongoing potential for software degradation.

> "There can always be a new layer of indirection or a reduction in performance."
>
> — Kehs illustrating the complexities and pitfalls in software development.

## Full Article

6th September 2026 If you continue to add floors and rooms to a building forever, it will collapse. Software faces no such constraint. The code can always get worse. There can always be a new layer of indirection or a reduction in performance. — Zach Kehs, There's No Limit to How Bad Code Can Get
