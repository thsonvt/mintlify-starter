## Summary

The release of datasette-mcp 0.2 introduces an array of objects for 'rows' in execute_sql, enhancing clarity for weaker models. This marks the first stable release of the plugin.

## Key Insights

## Full Article

"rows" from execute_sql is now an array of objects. Previously it was an array of arrays. This should help weaker models avoid losing track of which positional array element maps to which column. #1 Now depends on mcp>=2.1.1. This is the first non-alpha release of the plugin. I'm confident it's ready as I've been using it quite a bit myself.
