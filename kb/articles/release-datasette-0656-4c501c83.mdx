## Summary

The release of datasette 0.65.6 includes a backported security fix addressing a vulnerability related to database access permissions.

## Key Insights

> "Fixed a security issue where a database registered using add_database could be downloaded by actors who were denied access to it."
>
> — Description of the security fix in the release notes.

## Full Article

I backported a minor security fix from 1.0a43: Fixed a security issue where a database registered using add_database(db, name=..., route=...) with a route that differs from its name could be downloaded from /&lt;route>.db by actors who were denied access to it. [...]
